# Наставление — първите часове по FIP (вторник, зала 1211)

## Графикът

- Вторник, 1211: **блок 1** и **блок 2** = FIP lab. Диагоналът в клетката: горе-ляво = **нечетна седмица → подгрупа a**, долу-дясно = **четна → подгрупа b**. Всяка подгрупа идва **през седмица** → ~7 срещи/семестър = 5 упражнения + 2 буфера (консултации, защити). Провери в графика на факултета коя е седмица 1.
- Едно и също съдържание **два пъти в деня** (блок 1 → група X, блок 2 → група Y). След блок 1 запиши 3 неща, които променяш за блок 2.
- В същите блокове в 701 върви FIP лекция (друг поток) — ако лекторът въвежда материал, който твоите студенти още нямат, Упр. 1 е самодостатъчно: не зависи от лекции.

## До понеделник — подготовка (≈40 мин)

1. **Проверка в 1211 на компютър от залата** (10 мин; единствената стъпка, която трябва да е на място): вход в github.com → *Use this template* → тестово repo `fip-test` → *Create codespace* → редакторът се появява → `node --version` → `cd ex1 && npm install && npm start` → таб **Ports** → 8080 отваря страницата → `gemini` → вход с Google (кодът се поставя в терминала). Ако нещо не мине → IT: github.com, `*.github.dev`, accounts.google.com, WebSockets. После изтрий codespace-а.
2. **Teams до студентите** (шаблон долу): акаунти GitHub + Google, Student Pack, лаптоп ако имат.
3. **На проектора**: `fip-course-template` README → `ex1/README.md` → `PROMPTS.md`; `TU-materials/…/instructor/PLAN.md` отворен за разбора; `fip-test` за live демонстрация.
4. **Присъствие**: таблицата в края — ФН, repo, tag `ex1`.

## Ако…

- **Codespaces не тръгва** (мрежа/квота) → StackBlitz: `stackblitz.com/github/<user>/fip-<ФН>/tree/main/ex1` (само браузър; агентът = уеб чат Claude/ChatGPT) или лаптоп + VS Code + Live Server. Упр. 1 е една HTML страница — работи навсякъде.
- **Gemini входът виси** → Ctrl+C, `npm i -g @google/gemini-cli@latest`, `gemini`. За днес — Copilot Chat или уеб чат.
- **Половината без акаунти** → днес по двойки на един екран; предават до следващата си среща (2 седмици). Отбележи кой.
- **Групата изостава** → B4 и C за вкъщи; присъствие при tag с A + B1–B3.
- **Агентът е написал Част A** → студентът обяснява всеки ред или го пише наново пред теб. Без обяснение — без присъствие.
- **Студент пита „защо не просто ChatGPT да го напише"** → „Може. После ти ще го защитаваш на разбора и на изпита. Логът показва какво си проверил — това оценяваме."
